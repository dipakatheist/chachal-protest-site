# Chachal Protest Website

A simple, mobile-friendly static website template for a proposed peaceful public gathering at Chachal, Guwahati.

## Folder contents

- `index.html` — the website page
- `assets/style.css` — colours, layout, and mobile-friendly styling
- `assets/icon.svg`, `assets/favicon-32.png`, `assets/apple-touch-icon.png` — browser and phone icons
- `assets/og-image.png` — 1200×630 preview image used when the page is shared on WhatsApp, Facebook, X, etc.
- `README.md` — these instructions

## Preview on your computer

1. Extract the ZIP file.
2. Open the `chachal_protest_website` folder.
3. Double-click `index.html`. It should open in your browser.
4. The venue map link requires an internet connection.

## Customize before publishing

Open `index.html` in a text editor and replace:
- The sample “Why are we gathering?” text with your verified cause and demands.
- “Not decided yet” with the confirmed date.
- “To be announced” with the confirmed time.
- The contact section with organizer contact details you intend to publish.

Do not describe a date, permission, organizer, or demand as confirmed until it is verified.

### Also update the sharing preview

The page shows a preview image and link title when shared. In `index.html`, replace every
occurrence of `https://chachal-protest.example` with your real domain (for example
`https://your-site-name.org`) — it appears in the `canonical` link and in the `og:image` and
`twitter:image` tags. If you do not, social platforms will not find the preview image.

## Publish online

You can publish this static folder using GitHub Pages or Netlify:
- GitHub Pages: https://pages.github.com/
- Netlify: https://app.netlify.com/drop

For Netlify Drop, upload the extracted folder (or drag the project files into the deployment area). The homepage file must remain named `index.html`.

## Privacy and functionality

This is a static information website. It does not collect or transmit personal data, and it has no registration backend. If you later add registration, use a trusted form provider or secure backend and publish a clear privacy notice.

## Editing

Use any text editor, such as Notepad on Windows or a code editor. Keep `index.html` and the `assets` folder together.
